# 📊 INX Future Inc. Employee Performance Analysis

## 📌 Project Overview

This project focuses on analyzing employee performance at INX Future Inc. using data analysis and machine learning techniques. The objective is to identify the key factors affecting employee performance and build a predictive model to classify employee performance ratings.

## 🎯 Objectives

- 📈 Analyze employee data to understand workforce performance.
- 🧹 Perform data cleaning and exploratory data analysis (EDA).
- 🔍 Identify important factors influencing employee performance.
- ⚙️ Apply feature engineering and categorical encoding.
- 🤖 Train and evaluate models to predict employee performance ratings.
- 💡 Provide data-driven insights to support HR decision-making.

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas and NumPy
- 📊 Matplotlib and Seaborn
- 🤖 Scikit-learn
- 📓 Jupyter Notebook
- 🌳 Machine Learning — Random Forest Classification

## 🔄 Project Workflow

1. 📥 Data collection and preprocessing
2. 📊 Exploratory data analysis and visualization
3. ⚙️ Feature engineering and categorical encoding
4. 🧠 Model training and evaluation
5. 🎯 Employee performance rating prediction
6. 🔍 Analysis of important performance-related factors

## 🎯 Target Variable

**`PerformanceRating`** — the employee performance rating to be predicted by the machine learning model.

## 🏆 Expected Outcome

The project aims to help HR teams understand employee performance patterns, identify influential factors, and make informed workforce management decisions using machine learning.

## 📝 Conclusion

This project demonstrates the application of Python, data analytics, and machine learning to an HR analytics problem, from data preprocessing and visualization to predictive modeling and performance evaluation.
